# 📄 Currículo Online — Amanda Ramos Castilho
---

## 🧾 Sobre o Projeto

Projeto de **currículo online**, desenvolvido com **HTML5, CSS3 e JavaScript puro**, com foco em **design moderno**, **acessibilidade**, **responsividade** e **experiência do usuário**.

O site funciona como uma **vitrine digital completa**, apresentando informações profissionais, habilidades técnicas, projetos autorais, certificações e formas de contato — ideal para **recrutadores e empresas**.

---

## ✨ Funcionalidades

### 📌 Currículo Online Completo
- Sobre mim  
- Resumo profissional  
- Objetivo  
- Formação acadêmica  
- Habilidades técnicas  
- Ferramentas  
- Soft skills  
- Certificações  
- Diferenciais  

### 💻 Portfólio de Projetos
- Lista detalhada de projetos autorais  
- Links diretos para demonstração online (GitHub Pages)  

### 🌙 Modo Escuro (Dark Mode)
- Alternância entre modo claro e escuro  
- Preferência salva com `localStorage`  

### 📱 Design Responsivo
- Adaptado para desktop, tablet e dispositivos móveis  

### 🎨 UI Moderna e Elegante
- Gradientes  
- Animações suaves  
- Microinterações  
- Tipografia profissional  

### ♿ Acessibilidade
- Uso de `aria-label`  
- Estrutura semântica  
- Contraste adequado de cores
